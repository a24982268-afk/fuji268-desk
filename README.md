# 蹦火仔 接團台

富吉漁創內部用的接團工具：收預約詢問、排導覽員、產生 LINE 訊息。
網頁放在 GitHub Pages，資料存在店家自己的 Google 試算表。

- 網頁：`index.html`（不含任何密碼或金鑰）
- 後端：`apps-script/Code.gs`（貼到 Google 試算表的 Apps Script）

## 存取控制

- 打開網頁要先輸入共用密碼，密碼只存在 Google 那邊（存雜湊值），網頁裡沒有。
- 沒登入的人呼叫後端只會拿到「請登入」，看不到任何資料。
- 連續輸錯 10 次會暫停登入 15 分鐘。
- 登入後同一支手機 30 天內不用再輸入。
- 手機遺失或有人離職：打開試算表 → 上方選單「接團台」→「設定／更改登入密碼」或「讓所有裝置重新登入」。

## 第一次設定後端

1. 開一份新的 Google 試算表（https://sheets.new），命名為「蹦火仔接團台」。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把編輯器裡原本的內容全部刪掉，貼上 `apps-script/Code.gs` 的全部內容，按儲存。
4. 上方函式選單選「初始化」，按「執行」，依畫面授權（選自己的帳號 →「進階」→「前往…（不安全）」→「允許」）。
5. 回到試算表重新整理，上方會多一個「接團台」選單 →「設定／更改登入密碼」。
6. 回到 Apps Script：「部署」→「新增部署作業」→ 類型選「網頁應用程式」，
   執行身分「我」，誰可以存取「所有人」→「部署」，複製「網頁應用程式網址」。
7. 把網址填進 `index.html` 裡的 `API_URL`。

修改 `Code.gs` 之後要「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→「部署」，網址不會變。

## 船班與船位（防超收）

- **船隻**：「設定」頁的「船隻與載客上限」是每艘船的預設上限（預設金波羅 34、航海家16號 45、公主268號 45、航海家18號 42），
  新船型在這裡新增；輸入已有的船名＝改上限。存在試算表「船隻」工作表。
- **船班**：「船班」頁選日期，點選當天開的船（一艘船一天一班）。可以：
  - 改「當日船位」：只影響這一天，空白＝用預設上限。
  - 「標記停航」：這艘船當天不算船位；頁面會列出當天搭船的團，提醒通知改期，團單的「回覆客人」會多一個「停航改期」範本。
  - 下方「接下來 30 天」一覽每天的船位，點一下就跳到那天。
  - 資料存在試算表「船班」工作表（一天一艘船一列）。
- **怎麼算**：當日船位＝當天有開、沒停航的船的船位加總；已訂＝當天「已成單／導覽員已排定／已通知導覽員／已完成」
  且遊程要搭船的人數。待確認的人數另外列出，不算已訂。
- **哪些遊程要搭船**：「遊程」頁每個遊程可以設「要搭船嗎」，預設自動判斷（名稱有「海上」「海陸」「船」就算），陸上遊程不算船位。
- **提醒**：團單卡片顯示「當日船位 55／87，剩 32」；那天沒開船、停航或超收會標紅。
  成單、改日期或人數會造成超收、或那天沒開船時，會先跳出確認。
- **預約頁**：客人選海上類遊程與日期時，會看到「尚有名額／名額有限（剩不到 10 位）／已額滿／船班暫停／尚未安排船班」，
  不顯示船名與人數（最多約 5 分鐘延遲）。

## 團號、客人訊息、成單確認、客人填名單

- **團號**：每張新團單自動編號（建立日－當天第幾團，例如 `1018-03`），LINE 機器人回覆「已收到」時會附上，卡片標題旁也會顯示。
- **客人訊息自動歸檔**：客人之後在 LINE 傳的訊息，會記到他「還沒出發的那張團單」的「客人訊息」。
  沒被關鍵字自動回覆的訊息會標「客人有新訊息」並排到最上面；處理完按「標為已處理」。
- **成單確認卡**（LINE 來的團單）：「回覆客人」→「傳送成單確認卡」，客人會收到列出日期、集合時間地點、遊程、人數、費用、訂金的卡片，
  有「確認無誤」「需要修改」「填寫旅客名單」三個按鈕。客人按了會自動記在團單上（卡片顯示「客人已確認」或「客人要修改」）。
  已確認的團單如果改了日期、時間、人數、遊程、費用或訂金，確認會自動取消，提醒重新傳送。確認卡用的是推播，會用到 LINE 每月額度。
- **客人自己填旅客名單**：每張團單有專屬連結（在「旅客名單」裡，可複製或用 LINE 傳），客人在手機上一人一格填寫，
  會檢查身分證字號與日期格式，送出就直接存進團單。連結到出發日隔天失效，團單取消也會失效。
  網頁在預約頁網站的 `pax.html`（`fuji268` repo）。
- **自動提醒填名單**：每天早上 7 點（同船班名冊排程），3 天後出發、名單還不齊、從 LINE 來的團，自動傳一次填寫連結給客人。

## 訊息範本（設定頁可改）

接團台「設定」→「訊息範本」可以直接修改，存檔後所有手機同步（存在試算表「訊息範本」「自動回覆」工作表）：

- 「回覆客人」的範本：確認收到、確認成功、補問細節、日期客滿、停航改期、行前通知、填寫名單連結。
- 機器人自動傳的訊息：收到預約詢問、客人按「確認無誤」／「需要修改」後、出發前 3 天提醒填名單。
- 機器人關鍵字自動回覆：新增、修改、刪除、調整順序。

範本寫法：`{姓名}` `{日期}` `{人數}` `{團號}` `{集合時間}` `{集合地點}` `{遊程}` `{遊程內容}` `{名單連結}` 等會換成團單資料；
`{集合時間|待定}` 空白時顯示「待定」；`[ … ]` 方括號裡只要有欄位是空的，整段就不顯示。每個範本下方有即時預覽，「恢復預設」可回到原本內容。

## 待確認逾時提醒

「待確認」超過 24 小時的團單會標紅「已等 N 小時未回覆」並排在列表最上面，統計卡也會顯示幾團逾時。

## 船班名冊（出發前 3 天自動產生）

- 每張團單的「旅客名單」可貼上客人傳來的名單（姓名、身分證字號／護照、出生年月日、電話）。
- 在 Apps Script 執行一次「設定每日排程」後，每天早上 7 點會把 **3 天後**所有已成單團
  （已成單／導覽員已排定／已通知導覽員）的旅客整理成名冊，並重新產生 1、2 天後的名冊，
  放在雲端硬碟「蹦火仔船班名冊」資料夾（PDF 可直接列印，另有試算表版）。
- 同一天的名冊重新產生時，舊檔會移到垃圾桶；直接在試算表版上做的修改不會保留。
- 接團台「遊客資料」→「船班名冊」選日期後，也可以直接下載 **Word 檔（可編輯）**：
  - 「完整名冊」：含身分證字號／護照、出生年月日、電話，給船公司或保險用，請妥善保管。
  - 「報到點名表（無證號）」：只有姓名與出生年，加上「報到」勾選欄與備註欄，適合在報到處公開點名，避免個資外洩。
  - 兩種都會依團單人數排滿格數：還沒填資料的旅客留空白列（接續序號、格子較高），方便當場手寫補上。
  - 檔案在手機或電腦上直接產生，不經過後端，也不會存到雲端硬碟。
- 也可以在接團台「設定」頁，或試算表「接團台」選單手動產生指定日期的名冊。

### 第一次設定

1. 先照上面把 `Code.gs` 更新到最新版，並「管理部署作業」→ 編輯 →「新版本」→「部署」。
2. 到 LINE Official Account Manager（https://manager.line.biz）→ 選 @FUJI268 →「設定」→「Messaging API」→「啟用 Messaging API」，
   依畫面建立或選一個 Provider。
3. 到 LINE Developers（https://developers.line.biz/console/）→ 剛才的 Provider → 這個 Channel →「Messaging API」分頁：
   最下面「Channel access token (long-lived)」按「Issue」，複製。
4. 試算表上方選單「接團台」→「設定 LINE 機器人」→ 貼上 token →「確定」。畫面會顯示一串 Webhook 網址（結尾有 `?line=…`），複製。
5. 回到 LINE Developers「Messaging API」分頁 →「Webhook URL」→「Edit」貼上 →「Update」，打開「Use webhook」。
   （按「Verify」可能顯示錯誤，這是 Google 轉址造成的，不影響實際收訊息。請用手機傳「價格」給官方帳號測試。）
6. **先在正式帳號上測試（遊客不受影響）**：機器人預設是「測試模式」，只處理測試名單上的 LINE 帳號，
   其他遊客的訊息只記在「LINE 訊息」工作表、不回覆也不建單，照舊由真人回。
   - 用自己的手機傳一則訊息給 @FUJI268 → 到「LINE 訊息」工作表 C 欄複製自己的 LINE 使用者ID（U 開頭）。
   - 試算表選單「接團台」→「LINE 機器人測試名單」→ 貼上（同事的也可以，用逗號分開）。
   - 測試期間 LINE 後台的「自動回應訊息」維持原狀（遊客照舊收到），測試帳號可能會收到兩則回覆，屬正常。
   - 測試建立的團單在接團台刪除即可。
7. 測試沒問題後：試算表選單「接團台」→「LINE 機器人正式上線／改回測試」→ 確定上線，並做下一步。
8. 回到 LINE Official Account Manager →「設定」→「回應設定」：
   「聊天」保持開啟（真人還能回）、「Webhook」開啟，「自動回應訊息」關閉（不然會跟機器人重複回覆）。

Webhook 網址裡的 `?line=…` 等同機器人的鑰匙，不要公開；外洩時到 Apps Script「專案設定」→「指令碼屬性」刪掉 `LINE_KEY`，
再執行一次「設定 LINE 機器人」產生新網址並貼回 LINE Developers。

### 從接團台直接用 LINE 回覆客人

從 LINE 機器人建立的團單，在「回覆客人」裡每個範本都多一顆「用 LINE 傳給客人」（按兩次才會送出），
訊息會直接出現在客人跟 @FUJI268 的聊天室，也會記在「LINE 訊息」工作表。

機器人自動回覆用的是「回覆」，不算推播額度；但從接團台主動傳的屬於「推播」，會用掉官方帳號的每月免費額度
（依 LINE 當下方案，輕用量方案約 200 則／月）。額度用完時會顯示原因，改用「複製」到 LINE 貼上即可。

## 匯出遊客資訊（Excel）

- 接團台「遊客資料」頁 →「匯出遊客資訊（Excel）」，可選日期範圍與要包含的團，按「下載 Excel」。
- 「彙整」頁：日期、人數、旅遊項目、團數，同一天同一個遊程合併加總，最後一列是合計。
- 「明細」頁：一團一列，含大人／小孩、集合時間、團體／聯絡人、類型、狀態。
- 檔案直接在手機或電腦上產生，不用更新後端。
